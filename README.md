# Galaxy Hub

Single-page e-commerce showcase for **Galaxy Hub**, a tech retailer in Kigali, Rwanda. Customers browse phones, laptops, audio and accessories, request orders (pay on collection/delivery), get instant WhatsApp contact, and staff receive live order/form notifications on Telegram. Built with **Next.js 16**, **Tailwind CSS 4** and **Supabase** — no backend to manage, all admin CRUD is first-class.

**Live site:** https://galaxy-hub-website.vercel.app

## Tech Stack

| Layer | Technology |
| --- | --- |
| Framework | Next.js 16.2.10 (App Router, `"use client"` for interactivity) |
| UI | React 19.2.4, Tailwind CSS 4 (CSS-based `@theme` config), framer-motion |
| Language | TypeScript 5 (strict) |
| Data | Supabase Postgres + PostgREST (static mock data in `src/data/` as fallback) |
| Notifications | Telegram Bot API (staff group pings) |
| Linting | ESLint 9 (flat config) |
| Fonts | Manrope (`next/font/google`) + Oakes Grotesk (self-hosted) |

## Features

- **Landing page** — hero, deals, categories, brands, products, reviews, all in one scrollable page with smooth anchor navigation
- **Catalog** — category/brand pages, live search with full-screen overlay, deals pages
- **Responsive pagination** — 24 products/desktop, 18/tablet, 12/mobile with "Showing X–Y of Z" indicator
- **Cart** — persistent Supabase cart synced via a shared context, desktop dropdown + mobile bottom sheet, localStorage session persistence
- **Express Order** — no online payment; order requests with confirmation screen, confetti, WhatsApp follow-up button (`wa.me/250785288910`)
- **Sequential order numbers** — `GH-2026-000001` style, generated by a Postgres sequence/RPC
- **Admin panel** — products, categories, brands, promotions, reviews, hero and orders CRUD with image uploads, bulk delete via row checkboxes, order status tracking (pending → confirmed → processing → shipped → delivered / cancelled)
- **Telegram staff notifications** — new orders, contact messages, quote requests and order status changes are pushed to the staff Telegram group (best-effort, never blocks the customer flow)
- **Contact page** — form + store info + embedded map

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Configure environment variables

Copy the values from your Supabase and Telegram projects into `.env.local` (gitignored):

```bash
# Supabase
NEXT_PUBLIC_SUPABASE_URL=
NEXT_PUBLIC_SUPABASE_ANON_KEY=
SUPABASE_SERVICE_ROLE_KEY=

# Telegram staff notifications (see "Telegram Setup")
TELEGRAM_BOT_TOKEN=
TELEGRAM_CHAT_ID=

# Site URL used in notification links
NEXT_PUBLIC_SITE_URL=http://localhost:3000

# Optional: mobile price-fetch API (has a built-in default)
MOBILE_API_KEY=
MOBILE_API_BASE_URL=
```

### 3. Apply the database schema

The project uses the [Supabase CLI](https://supabase.com/docs/guides/cli) with SQL migrations in `supabase/migrations/`:

```bash
npx supabase login
npx supabase db push
```

### 4. Run the dev server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Telegram Setup

1. Create a bot with [@BotFather](https://t.me/BotFather) and copy the token into `TELEGRAM_BOT_TOKEN`.
2. Create a group (e.g. "Galaxy Hub Circle"), add the bot as a member, and send any message so the group has a chat id.
3. Get the chat id (for a group it is negative, e.g. `-1001234567890`) via `https://api.telegram.org/bot<TOKEN>/getUpdates` and put it in `TELEGRAM_CHAT_ID`.

Messages use MarkdownV2 — all dynamic values are escaped; any user input is safe. Notifications are best-effort: a failure is logged and swallowed so checkout/form submissions are never interrupted.

### Key conventions

- `@/*` path alias maps to `./src/*`
- Theme colors (`ivory`, `ocean`, `ocean-dark`, `ocean-light`, `accent`) are defined in `globals.css` via the `@theme` block
- Staff notifications flow through `sendNotification()` in `src/lib/notifications/index.ts`
- Server actions live in `src/actions/*`, always best-effort for the customer flow
- Utility scripts at the repo root (`update_mock.js`, `update_page.js`, `update_trending.js`) regenerate parts of the static data layer

## Deployment

Deploy on [Vercel](https://vercel.com/new?utm_medium=default-template&filter=next.js&utm_source=create-next-app&utm_campaign=create-next-app-readme):

1. Import the repository.
2. Add all environment variables from `.env.local` in **Project → Settings → Environment Variables** (Production + Preview).
3. Deploy — the build runs `next build` automatically.

After a deploy, always re-check the Telegram group: place a test order and submit the contact form to confirm notifications arrive.
